# Como contribuir

1. Faça um fork deste repositório.
2. Crie uma branch para sua alteração: `git checkout -b melhoria/minha-alteracao`.
3. Faça as alterações e teste o código.
4. Envie um Pull Request explicando o que mudou.

Mantenha a interface em português do Brasil e não envie banco de dados local,
senhas, tokens, informações pessoais ou arquivos gerados de uso real.
